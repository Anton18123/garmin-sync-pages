Garmin Sync — Privacy Policy

Last updated: 17 October 2026

Garmin Sync is a personal, non-commercial tool. Its only user is its operator, who authorizes it to access their own Garmin Connect and Google Drive accounts.

Data the app accesses

  • Garmin Connect: the operator's activity list, original activity files, and activity metadata.
  • Google Drive: the file names, sizes, and contents of files in one designated folder ("Sports and Fitness/Garmin").

How the data is used

The data is used only to copy the operator's activity files into that Drive folder and to confirm that each copy is complete. Copies of the files and the sync state are kept on a private server controlled by the operator.

Sharing

No data is sold, shared with third parties, used for advertising or analytics, or used to train AI or machine-learning models. Use of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

Security and retention

Credentials are stored only on the operator's server and are readable only by the system user that runs the sync. Data is kept until the operator deletes it.

Revoking access

Google access can be revoked at any time at myaccount.google.com/permissions.
