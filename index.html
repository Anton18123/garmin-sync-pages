Garmin Sync

Garmin Sync is a personal, non-commercial tool. It is operated by a single person for their own use and is not offered to the public.

Once an hour it copies the operator's own workout files from Garmin Connect (the original activity file and a JSON summary) into a single designated folder in the operator's own Google Drive. After each upload it reads the file back to confirm that the copy is complete and undamaged.

Google data access

The app uses Google OAuth to access Google Drive. It only lists, uploads, and reads files in the designated Garmin folder, and it deletes only the small temporary test files it creates itself to check access. It does not read, change, or share any other Drive content.
